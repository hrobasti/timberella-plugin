# Security policy

## Supported versions

Only the latest release of Timberella receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately instead:

1. Open the [Security tab](https://github.com/hrobasti/timberella-plugin/security) of this repository.
2. Click **Report a vulnerability** and describe the problem, the affected version and how to reproduce it.

The report stays private until a fix is released. You will get an answer as soon as possible.
